# Analisador de Pagamentos

Projeto desenvolvido em Python para analisar dados financeiros de uma planilha Excel, calcular indicadores e gerar relatórios formatados.

## Funcionalidades

- Leitura de planilhas Excel com pandas.
- Tratamento inicial dos dados.
- Cálculo de indicadores financeiros.
- Identificação do maior pagamento.
- Análise por forma de pagamento.
- Formatação monetária em reais (R$).
- Geração de relatório Excel formatado.
- Criação de gráficos com Matplotlib.

## Tecnologias

- Python
- pandas
- Matplotlib
- openpyxl
- Excel

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Instale as dependências:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Coloque `Planilha de Pagamentos.xlsx` na pasta do projeto.
5. Execute:

   ```bash
   python analise.py
   ```

## Dados

A planilha de exemplo utiliza dados fictícios para fins de estudo.

## Objetivo

Praticar análise e tratamento de dados, automação de relatórios e visualização de informações com Python, desenvolvendo habilidades relevantes para a área de Dados e Inteligência Artificial.
